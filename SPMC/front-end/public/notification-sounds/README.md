# Notification Sounds Folder

## 📁 Place Your Custom Sound Files Here

This folder contains the notification sound files used by the SPMC Referral System.

## 🎵 Required Sound Files

Place your `.mp3` files here with these exact names:

### Standard Sounds:
- `default.mp3` - Default notification sound
- `chanak.mp3` - Chanak sound (your custom sound)
- `bell.mp3` - Bell sound
- `chime.mp3` - Chime sound
- `ding.mp3` - Ding sound
- `beep.mp3` - Beep sound

### Urgent Sounds (Optional):
- `chanak-urgent.mp3` - Urgent version of chanak
- `bell-urgent.mp3` - Urgent version of bell
- etc.

## 📝 File Requirements

- **Format:** `.mp3`
- **Duration:** 1-3 seconds (recommended)
- **File Size:** Under 100KB (recommended)
- **Sample Rate:** 44.1kHz or 48kHz
- **Bit Rate:** 128kbps or 192kbps

## 🚀 Quick Start

1. Copy your `chanak.mp3` file to this folder
2. Refresh the application
3. Click the speaker icon (🔊) in the navigation bar
4. Click the music note icon (🎵) to select your sound
5. Test it by clicking the play button (▶️)

## 💡 Tips

- Keep sounds short and pleasant
- Normalize audio volume for consistency
- Test sounds before deploying to production
- Use royalty-free or licensed audio only
